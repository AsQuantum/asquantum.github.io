# 工厂长期产率：精确迭代与解析模型

当前生产版本：`iteration-58`。新引擎独立运行，不加载旧直接求解器。本文按数学主题维护，后续在对应小节修订，不再按版本追加章节。所有结论均以其证明前提为限；任意组合的长期解存在性、可判定性和有限时间内求解完备性尚未证明。

## 1. 模型、输入与输出

### 1.1 统一物理规则

从空仓库、空机器缓存、空线路、零冻结相位开始，时间单位为0.05秒，距离单位为0.1格，带速为1距离单位/tick，包间距10，接口冷却20tick。当前实际模拟器为独立对拍参考，而非数学结果来源。机器生产批次、每种原料容量3批、成品容量20批；仓出缓存3件、收发及补货各有时钟；电脑缓存10件、消费1件/s；分流和汇流缓存/轮询/过滤以及原料FIFO严格保留。仓入立即接收入库。每tick顺序为带运动及普通接收、物理入库、仓出补货、按优先级冻结服务、机器生产/发送/汇流接收。仓出按实际接口优先级，冻结按配置顺序。具体边界以当前 exact-kernel.js 和 simulation.js 对拍为准。

几何审计独立：摆放警告、悬空、物料不匹配、缺料、重复或失效端点均按实际运行规则求率，不以 checkPath 否决全图。未连接带流量0；错误物料可在带尾拒收并产生反压；重复输出选择第一条，普通重复输入共享冷却，汇流遵循第一记录。独立缺料机器不影响其他组件。真正不明确的损坏记录、重复身份或不安全数值仍须报告。

### 1.2 三种收支

- 实际：从空启动在真实库存和竞争条件下的长期收入I、支出O，净值I−O。
- 潜在：固定实际入库事件日历，单独解除目标物料k的库存门，求其条件需求D；潜在净值I−D。其他库存仍遵守边界；条件新增入库不反馈到实际日历。不可用平均入库率替代时序。
- 透支：解除所有仓库库存限制，重新计算全模型的收入及支出，取净值。不是实际收支的简单倍乘。

所有内部产率使用精确整数/有理数，单位件/s；界面换算件/min。机器长期有效周期为完成率倒数，确定零率为∞，未知为null/—。部分解不能把共享物料部分和冒充完整总和。数学标签“精确解”“迭代解”“迭代+精确解”标明算法来源，迭代亦为精确状态转移而非浮点拟合。生产诊断仍 certified:false。

## 2. 精确状态、周期及加速

### 2.1 状态与周期证书

控制状态包含机器有序原料FIFO、成品、分汇流指针、忙碌/进度、接口剩余冷却、线路有序物料及整数位置、冻结相位；库存按实际可读守卫区分低库存精确值和高库存类，外生边界日历包含周期相位。重复控制与守卫类不是任意充分条件：库存位移必须保证未来转移不变。周期长度P（tick）和计数差ΔC给出精确率20ΔC/P。累计服务差给出冻结运行率。完整重放可验证控制、库存、计数、服务、守卫和日历；可达性验证还需重放真实启动前缀。现有证书与求解器共享转移内核，不宣称完全独立形式验证。

仓库保守充足阈值为读取接口数及冻结单tick最大消耗/保留之和。正漂移库存如果整轮不低于阈值则可无限平移；负漂移读库存不能直接宣称无限周期。符号守卫逐事件记录比较阈值的上下松弛量。令d为周期库存差，安全重复次数由全部守卫不等式（正/负漂移分别受上/下界）及库存非负限制取最小。有限平移同时更新库存、计数、冻结服务、逻辑时间；到边界后继续真实转移。可选快进先用BigInt预检安全整数范围，超过范围缩短或拒绝跳跃，不能舍入。未启用的有界成品缓存平移也必须证明每次容量/非空守卫不变；84机实验收益不足，保持关闭。

### 2.2 计算表示与事件跳跃

- 近期128、稀疏128（每16检查点采样）和一个倍增锚点；默认20tick取检查点，单搜索最多257个完整状态，不是整个程序RAM上限。计数向量索引追加、延迟物化，完整键无碰撞近似。首轮未完成可暂停最多4个搜索并恢复。
- 空闲跳跃取下一传送、冷却、生产、消费、冻结取整或外部入库事件的保守下界；到事件边界仍按原同tick顺序执行。不存在以平均流量替代状态转移。
- 冷却用绝对截止时间E，剩余max(0,E−t)，快照仍写相对冷却。已证明的整周期平移不推进独立运动钟。
- 长带惰性运输：对队首相对序号j、虚拟发送时刻s_j、间距d、终点L、释放边界B，x_j(t)=min(t−max(s_j,B+jd), L−jd)。接收首件时B'=max(B,t−L)+d，剩余包不瞬间前跳。首尾读取O(1)，出队摊还O(1)，完整状态O(n)；整带运动由O(n)降至O(1)。默认长度≥32格采用惰性整数表示，短带仍逐件整数移动。实际同步批次≥20tick且步长0.05秒时同样使用，结束前物化回原item/distance数组供画布及编辑使用，运输批次O(Kn)降至O(K+n)，另计真实收发和机器处理。32格和20tick为实测工程阈值。
- 固定入库日历按(阶段/物料事件、相邻间隔)循环词用KMP寻找最短重复，无需展开整个P数组；删除仅非读取物料的信用，不删除影响控制的事件。

### 2.3 冻结精确格点

冻结工厂物料名义率绝对值r_i=p_i/L，L为分母LCM。共同服务时间s，选M=lcm(20L, 所有负输入p_i)，满tick服务单位u=M/(20L)，服务的真实时间单位为L/M秒。相位a_i/M；服务t单位后转移量floor((a_i+p_it)/M)，新相位为模M余数。有限可用库存w_i给输入服务上限(w_i M−a_i)/p_i，输入p_i整除M使上限整数；取全部限制最小值。所有输入至少有1件才可启动服务；每次原子扣料及保留顺序不变。输出p_i无需整除M。超过4096位公共格点则使用同一转移的精确分数表示，不是旧求解器。实际模拟冻结相位也保持精确分式。浮点只用于展示和墙钟，不参与物理阈值。

## 3. 拓扑依赖与解析特例

### 3.1 组件划分

物理连接含反压，视为双向依赖；库存读者与可能写入者、共享非自由库存的读者必须合组。仅共享不读取的入库物料可独立汇总。透支解除库存限制后按物理独立组及冻结单元划分。固定实际入库日历的潜在模型不允许新入库反馈，故可按非自由库存与物理连接进一步精确投影，保留原冻结阶段占位及日历相位。物料可达性工作队列按(机器,物料)传播一次，O(K(V+E))上界；结构可达不是正产率证明。

同一组件尝试下述解析定理，条件不满足、展开规模或证明时间超限则交回本版精确周期迭代，其他独立组不必联合迭代。共享仓库实际反馈组暂不强行剥离自主供给树。

### 3.2 结构零及自主生产

空启动无自主源/仓库供料/冻结演员的正原料需求组件，没有首次物料事件，所有长期流为0。无仓入、仓出、电脑和冻结演员的有向无环有限缓存网络，按逆拓扑归纳每节点仅有限次生产与发送，长期率为0，复杂度O(V+E)。不可把存在物理环或有终点的复杂网络一律归零。

自主源直连单一仓入、无竞争、物料兼容时，批量Q、生产周期T秒，率min(Q/T,1)件/s，完整机器/带/仓库计数守恒。整数tick形式P=20、生产周期T_tick、运输延迟D=10*带格数，首件F=T_tick+D。t<F累计入库0；x=t−F，若T_tick≤QP，N(t)=floor(x/P)+1；否则N(t)=floor(x/T_tick)*Q+min(Q,floor((x mod T_tick)/P)+1)。下一次到货由N(t)直接计算，无需物化前缀，区间计数N(h)−N(l)。

### 3.3 有限缓存生产树

仓入单接口为根，向上游反推：每台配方机器唯一输出，每种原料唯一兼容供料带，叶为自主生产，空启动，无仓出、分汇流、冻结、竞争或有向环。深度不是限制，事件图展开规模是限制。多棵互相独立树可接不同仓入或同一仓入的不同接口，逐根汇总；共享分流、多源同物料、混料、断头共享支路仍迭代。

令S_n、C_n为第n批开始/完成，D_i、A_i为第i件发送/接收。T为加工tick、Q为批量、L为整数运输长度、B=L/10+1。负/零序号约束不参与max。自主源C_n=S_n+T−1且后批S_n≥C_(n−1)+1；加工机C_n=S_n+T、S_n≥C_(n−1)，并要求每种原料a的第na件已到达。成品容量约束S_n≥D_((n−20)Q)+1。发送D_i=max(C_ceil(i/Q),D_(i−1)+20,A_(i−B)+10)。接收A_i≥D_i+L、A_i≥A_(i−1)+20，下游加工还需A_i≥S_(ceil(i/a)−3)+1。反压和输入缓存均在事件图中，不是假设无反压。

沿配方守恒递推各机相对根批率ρ，取分母LCM H，以每轮Hρ批及对应传输事件构造非负整数滞后h及整数时间权w的Max-Plus图。零滞后边须无环。候选λ从机器/端口名义容量下界max(NT,NQ20)起，用差分约束φ_v≥φ_u+w−hλ验证；发现正权闭环则以精确Σw/Σh提高λ，最终可行相位上界和容量/闭环下界吻合。根批率20H/λ，其他按ρ缩放。有限缓存及守恒保证长期率相同。默认最多2048事件顶点、32证明轮、森林解析40ms，超限回本版迭代。缺料树可用拓扑逆序证明必要原料不可达；唯一终点不能首次收到产品且各节点有限缓存、无环，则整树长期率为0。不得将可达性当作正流率证明。

### 3.4 冻结组件精确率

仅冻结演员且空启动：正净值自主源无条件满负荷；透支全部满负荷。若每演员至少有一个负输入且没有自主源，则无法产生第一个服务tick，实际全零。固定实际日历为空，潜在目标k放开后，只有唯一负输入为k的演员可满负荷，其名义消耗和为D_k，其他仍停机。透支所有输入放开。这包括独立缺料F2及无源循环。

严格盈余：D_k为全部演员对k的名义消耗和。已证最终满负荷的源供给和S_k若严格大于D_k，则累计整数供给减去消耗最终无界增长（取整偏差有界），从某时起库存永久高于全部单tick门槛及保留。一个演员所有输入已证永久充足后也最终满负荷，将其供给加入工作队列。全部演员获证才输出名义实际/潜在/透支率；部分可达、等量、供料不足、内生竞争无法证明时交回精确迭代。算法O(F+K)次图/有理数操作，另计分数位数。含实体机器的混合组件保持原依赖规则。

## 4. 运行时、缓存与界面

正式资产为 iteration-worker.js（HTTP）、iteration-offline.js（file://同源Blob）、iteration-display.js 和 ui/theory-worker.js；共享算术与物理编译在 math/arithmetic/rational.js、math/graph/symbolic_physical_spec.js。旧 steady-certified 系列、旧直接数学文档和测试仅历史参考。修改Worker依赖执行 python tools/build-iteration-worker.py；同步更新版本及页面资源。用户打开静态网页无需构建或联网计算。

首轮约400ms/4000tick，后台继续已有搜索；总墙钟60秒，完整后台不再有216万tick独立限制（测试API可指定更小步数）。到期后未知保留，首轮已知值不清零。实际/透支和固定日历条件需求可并行，按设备CPU与内存提示自适应1–4个Worker，嵌套Worker失败时尝试同版串行；file://离线亦可用。暂未在真实手机实测峰值RAM。页面保持可交互；编辑改变规范布局时取消旧任务；无效编辑不重算。

缓存键=规范机器/线路记录+有序激活冻结工厂的物料-精确速率列表（每组物料排序；组优先级和分组保留；名称、关闭项、零项不影响键），不含当前实际库存。缓存完整结果，LRU最多12项；独立组件另以最多1MiB的共享LRU保存，持久化合计仍受2MiB限制，localStorage失败时内存保留；版本更新使旧算法缓存失效。实际及潜在组件仅在整个组件的所有查询均完成时缓存；透支独立缓存。身份包含物理语义（机器配方、端口、线路、优先级、冻结演员有序收支等）及仓库读写依赖。新冻结项仅在实际仓库关系改变时使相关组失效；内部配方物料不构成仓库依赖，独立已证组件无须重新迭代。全厂与组件缓存分别保存，共享组件只序列化一次；跨刷新可复用。缓存缺失、被淘汰或未解组件仍需求解。首次求解墙钟含Worker启动与续算，以毫秒整数存入缓存，命中时展示原耗时。表头含迭代显示“迭代+精确解 · 用时X.XXXs”或“迭代解 · 用时X.XXXs”；纯解析显示“精确解 · 件/分钟”。诊断默认收起，列出求解方法、未知、缓存、搜索统计及异常；时间进度条不是完成百分比。

## 5. 失败边界与发布保护

正常缺料/断头/摆放警告、解析不适用、可选优化超限不属于数学报错。解析或投影内部异常时记录诊断，并尝试当前精确迭代/完整条件模型；若转移内核仍异常，标记该组件未知，保留其他已解组件。部分和不得冒充完整总量；不缓存部分结果，不调用旧求解器补值。安全整数快进预检只缩短安全跳跃，不改变真实计数。真实极端整数累计超出表示容量仍可报错；浏览器Worker/Blob/资源加载、异常退出、损坏数据仍可能失败。潜在条件需求低于实际需求时拒绝发布该字段；一般反事实一致性尚未完全证明。有限时间与有限内存无法保证所有组合都完整求解。

终止性：有限控制且所有读库存有界、透支模型，以及满足既有单无界读库存条件的有限控制模型，可证明周期或平移周期存在；有限相位格点并不代表可接受的周期长度。多无界库存一般终止性未证，暂不作为工程优化目标。严禁浮点容差周期、拟合有限窗口平均、按AST查预设答案或使用旧直接求解器填补未知。
