# 通用工厂长期产率：按仓入线路拆分的数学模型

**目标：**对任意机器、线路、仓库布局进行结构建模和长期速率求解。机器 ID、线路 ID 只作为引用；不使用 AST1 的固定编号或观察到的产量作为算法条件。不依赖每 0.05 秒的执行顺序。建图成功不等于所有实际长期速率都已被证明。

## 一、输入抽象

任意布局 L=(M,E,W)。

- M：机器，每台包含 0～N 个输入端口、过滤器、按物料独立或混合共享的有限输入缓存、内部配方/分流/汇流逻辑、有限输出缓存、0～N 个输出端口。
- E：有向物理线路，每条线路包含上游机器和端口、下游机器和端口、可能传送的物料种类。每条线路总吞吐量不超过 1 件/s；多物料共用同一额度。
- W_i：按物品 i 分类的共享无限仓库。对同物品的所有仓入、仓出访问同一个库存池，不能按设备配对建立私有库存。
- 普通配方机 m：每批消耗 a_(m,i) 件原料 i，生成 b_(m,j) 件成品 j，耗时 T_m。
- 仓入：接受匹配物品后立即计入对应 W_i；多个输入端口没有额外的设备级共享 3 件 FIFO。因此，同一仓入设备的不同输入线路不因仓入本身而耦合。
- 仓出：指定一种物品；每台仓出独立缓存 3 件，针对同物品仓库的预留按游戏已有优先级处理。

**关键：上游生产子图的资源共享，与仓库按物品共享，是不同类型的关系。**

## 二、把每条仓入线路作为独立终点

取所有接入仓入机器的有效线路组成集合 E_in。

对于每条 e∈E_in，以 e 的发送机器为逆向搜索起点，沿有向线路逆向追踪所有上游机器：

\[
U(e)=\operatorname{ReverseReachable}(\operatorname{source}(e),E).
\]

不包括 e 的末端仓入机器。反向遇到仓出设备，只作为**物理供应起点**，本阶段不跨入共享仓库追溯物品的来源；仓库关系留给下一层。

每条终点记录：
- terminalRoute：末端线路 ID
- warehouseIn、warehouseInPort：末端仓入机器和端口
- upstreamMachines、upstreamRoutes：所有可达上游机器与相关线路
- sourceGeneratorRoots：不消耗原料的源头生成器
- warehouseOutRoots：仓出机器起点
- independentOfWarehouseOut：上游机器是否没有仓出

一台仓入即使有 3 条入库线路，也首先创建 3 个终点，而不是默认合并成一个。若其中一条线路运输混合物品，也仍是**一条物理线路**；其不同物品的速率共用线路总容量。

## 三、哪些终点应当合并成同一求解子图？

设 R(e)⊆U(e) 为线路 e 的全部起点机器（仓出、生成器）。若两个终点共享起点：

\[
R(e_1)\cap R(e_2)\ne\varnothing,
\]

就应合并；但只检查起点**不充分**。闭合机器环可能没有仓出或无原料生成器，却仍让不同终点共同占用 FIFO、处理与分流容量。

通用合并判据：

\[
\boxed{e_1\sim e_2 \iff U(e_1)\cap U(e_2)\ne\varnothing.}
\]

使用并查集 Union-Find 取得其**传递闭包**，输出一个个不共享上游机器资源的终点组。

- 共用源头、加工机、分流器、汇流器、有限 FIFO：**合并**。
- 共用仓入机器，但逆向机器集合不相交：**不合并**。
- 仓入物品名称相同或使用同一共享库存：第一层**不合并**；仓库依赖在第二层处理。
- A/B 共用机器，B/C 共用机器：A/B/C **全部合并**，无须 A/C 直接相交。
- 若将来增加独立于机器之外的共享资源，则把该资源加入交集键；当前机器/线路结构用共同上游机器判据即可。

示例一：源头 A→配方 A→仓入端口 0，与源头 B→配方 B→仓入端口 1；即使终点是同一仓入设备，也形成两个组。

示例二：源头→分流器→配方 C→仓入端口 0，以及该分流器→配方 D→仓入端口 1；因共同上游分流器，两个终点合并求解。

### 对应实现

- factorySteadyWarehouseCutGraph(layout)：遍历真实仓入线路，分别逆向追踪，建立按物品的唯一仓库节点及依赖有向图，再求强连通分量 SCC 和拓扑顺序。
- factorySteadyGroupWarehouseEntryCones(warehouseInRoots, layout)：对每条末端线路建立逆向锥，遇共同上游机器时用 Union-Find 合并。
- entryConeGroups.groups：资源合并之后的求解子图，包含末端线路、上游机器、共享机器、上游仓出起点和可入库的物品。
- entryConeGroups.groupByRoute：末端线路映射到求解组。
- entryConeGroups.independentGroups、dependentGroups：按是否需要仓出分类。
- inputFilteringMayBlock、incompatibleTerminalMaterials：仓入过滤器可能拒绝的物品，不允许把潜在不兼容物品默默算作成功入库。

**函数不包含 AST1 机器编号的判断。** 增删连线会自动改变其输出。

## 四、以按物品共享仓库为第二层依赖图

每种物品创建唯一 W_i，构造有向边：

\[
C_k\rightarrow W_i
\quad\text{当求解子图 }C_k\text{ 向仓库存入 }i;
\]

\[
W_i\rightarrow C_l
\quad\text{当求解子图 }C_l\text{ 有物品 }i\text{ 的仓出起点。}
\]

同一种物品的多个仓出都指向同一个 W_i，不复制仓库。第一层独立的多个生产子图可以向同一个 W_i 供料，而无需在第一层合并它们。

对第二层依赖图使用 Tarjan SCC 得到强连通分量，将其缩点成为有向无环图，按照拓扑顺序安排求解。位于同一个 SCC 的反馈必须**联立**，不能强制按一个方向传播。

优先顺序：
1. 全部**没有仓出起点**的生产组：先计算其向共享仓库的独立供给。
2. 将可证实的入库率作为 W_i 的外生供给。
3. 仓出依赖组：根据该物品的库存供给、优先权和下游需求确定取货与机器产率。
4. 如果 SCC 包含仓库反馈，整个组联立相互影响的供需，而不是对环执行单向计算。
5. 若一个工作区间不能证明唯一且符合初始库存/实际调度的可达性，仅给出候选值与约束，不假装已经得到实际精确长期产率。

## 五、每个求解组要建立的纯速率方程

单位统一为件/s，展示时可乘 60。

### 变量

- f_(e,i)≥0：线路 e 上物品 i 的长期**实际通过率**。
- ν_m≥0：配方机器 m 的长期实际批次/s。
- g_i：物品 i 的仓库净库存增长率。
- 不把机器停机时间占比作为新的用户输入参数；可在求得 ν_m 之后再计算加工占比 ν_m*T_m。

### 配方守恒

在有限机器内部缓存长期不净积累的稳态下：

\[
\sum_{e\in E^{in}_m}f_{e,i}=a_{mi}\nu_m,\qquad
\sum_{e\in E^{out}_m}f_{e,j}=b_{mj}\nu_m.
\]

对于加工能力：

\[
0\le\nu_m\le1/T_m.
\]

### 线路容量

\[
\boxed{\sum_i f_{e,i}\le c_e=1\;\text{件/s}.}
\]

同一线路多个物料共用上界，不允许每种物料各有 1 件/s。

### 共享仓库守恒

\[
\boxed{g_i=\sum_{\text{仓入}}f_{e,i}-\sum_{\text{仓出}}w_{m,i}.}
\]

持续长期取出率不能要求有限初始库存无限下降；初始多 100 件只影响前期和可能的可达运行区间，不代表长期永久供应源。

### 工作守恒、供给/需求和分流约束

只用守恒和上界不能排除假零解。必须再表达上游的**潜在供应能力** S、下游的**可接收需求** D，以及工作守恒。无竞争、持续兼容的理想速率区间可以使用：

\[
f=\min(S,D,c_e).
\]

多输入配方、输出不堵塞的理想工作区间：

\[
\nu_m=\min\left(1/T_m,\min_i S_{m,i}/a_{mi},D_{m,out}/b_m\right).
\]

这些**不是**有多物品 FIFO、分流轮询、共享汇流和仓出优先竞争时无条件成立的公式。对于竞争节点，应由其现有选择规则建立**候选受限工作区间**，联立流率等式与容量/阻塞不等式，过滤不一致候选，再证明从实际初始条件可达。不要将已受反压的实际 f 重新当作未受限供给 S，否则会产生任意低速率或 0 的伪解。

## 八、任意 n 个仓出 / 分流出口及多层联立求解（2026-11-24）

本节是抽象模型，不依赖 AST1 机器编号；所有对象来自输入的机器、配方、过滤器和线路表。

### 8.1 n 台同物品仓出：逐个优先扣减（在可证明的工作区间下）

将物品 i 的全部仓出按**真实模拟器的数字机器 ID 优先顺序**排列为 o_1,...,o_n。令 I 为已知可持续仓入流率，D_j 为经过全部下游依赖计算后的可持续接收需求，C_j 为物理输出速率上限：

\[
R_0=I,\quad
f_j=\min(R_{j-1},D_j,C_j),\quad
R_j=R_{j-1}-f_j\;(j=1,\ldots,n).
\]

\[
g_i=I-\sum_{j=1}^n f_j=R_n\ge0.
\]

例：入库 80 件/分钟，优先顺序的需求为 60、11、20 件/分钟，单仓出最多60件/分钟，则流率为 60、11、9，库存增长为0。若实际总需求小于入库，剩余会积存，不可强制收支平衡。

**关键前提**：D_j 是下游实际可行需求，而不是一个独立给定或凭标称加工周期猜测的参数。如果任一仓出补回同一种库存、共同使用了其他共享机器或下游分流网络，必须先联立反馈 SCC，再求 D_j。每台仓出还有真实 3 件预留 FIFO；公式为适用的理想工作区间速率，不是所有物理布局的已证明精确平均值。

对应代码：factorySteadyIdealWarehousePriorityRates(inflow,outlets,options)，支持任意 n 台仓出、精确有理数、机器 ID 排序、未知需求报错；factorySteadyWarehousePriorityModel 和 factorySteadyBuildEquations 的优先顺序已与 simulation.js 对齐。测试 tests/steady-n-outlet-rates.test.js 含 80 台出口和改变数组顺序的布局。

### 8.2 n 个分流出口及相互递归

对单一分流器、持续供货且各出口兼容且 RR 适用的理想工作区间，设共有 n 个出口及已计算的需求上限 D_j，则：

\[
f_j=\min(D_j,\lambda),\qquad
\sum_j f_j=\min(S,C_{\rm shared},\sum_j D_j).
\]

局部函数 steadyExactWaterfill(supply,caps) 已支持**任意 n 个出口**。但是它**不是全局递归求解器**：后面任意多台机器的原料需求、其他分流器、缓存反压都可能改变这里的 D_j。若出现混合 FIFO 队首阻塞、过滤器冲突或实际 RR 工作区间不满足上述条件，不得硬套此式。

### 8.3 机器任意多层连接、多个 B/C 互连甚至反馈环

对于任意有限机器图，先由仓入线路建立逆向上游依赖锥并合并真实共享资源，再由按物品唯一共享的仓库节点连接仓入/仓出，求强连通分量 SCC 并缩点生成 DAG。

- 无环且供需独立的部分可按拓扑顺序传播潜在供应，并沿下游反向约束可持续需求；必要时在同一子图联立配方约束。
- 有环的 SCC 必须将全部相关流率 x 联立为分段固定点系统 x=Φ(x)，检查物理速率上限、库存非负、调度工作区间和初态可达性。不能递归遇到已访问的机器就假设某个流率。
- 所有设备与连接都根据 layout 自动生成，没有 A→B→C 三层的数量限制。图算法可处理任意有限组合；但潜在工作区间组合数量可能随图规模迅速增长。

**当前实现与缺口：**通用图遍历、仓库 SCC、配方守恒有理数消元、局部 n 出口 RR 水填充、局部 n 仓出优先扣减已经具备；缺少自动把**所有互相影响的机器、分流器、仓出**联立并判定正确工作区间的通用全图求解器。历史 AST1 的条件性例子不能代替这部分算法。


## 八、多起点、多终点与物理闭环（2026-11-24）

新增通用结构层 `scripts/engine/steady-generic-network.js`。**起点/终点是物理线路求解边界，不等于所有机器的速率已经求出。**

- 起点：任意配方零原料生成器以及指定物品的仓出；仓出只是物理起点，它是否能够持续出货仍取决于按物品共享的仓库。
- 终点：任意仓入输入线路及量子计算机的实际接入线路；相同仓入的不同输入线路不强制共享队列；计算机的实际共享输入 FIFO 会产生约束耦合。
- 中间：配方、分流、汇流任意层级与合法物理连接，可以存在不同设备之间的有向闭环。
- 两个终点的逆向锥共享同一台非终点设备时，对相关物理约束联立；使用并查集合并传递耦合。每个起点的同物品仓库依赖仍交给第二层共享库存节点处理。
- 用 Tarjan SCC 独立检查**物理线路的循环**，不混淆「物理回路」与「仓入→同物品库存→仓出」的间接反馈。分流器连接另一分流器不是循环；只有存在返回路径才构成循环。
- 缺少线路、开放线路、缺少配方原料是可计算的停机/零流率情况，不作为图拓扑错误；非法端口或线路几何错误仍由连接验证层处理。

### 物理反馈环的平均流率关系

假设有「外部输入 I → 汇流 → 分流 → 仓入 O」，且分流的一条输出回到汇流，内部回流为 R。在内部有限缓存的长期平均流率存在且缓存不持续增长时：

\[
 I+R=O+R \quad\Longrightarrow\quad I=O.
\]

这个恒等式**没有确定 R**。它说明无论反馈环对流率造成多少影响，都不能仅从物料守恒推出环内循环速度。真实 R 要由共用传送带带宽、FIFO、物料过滤、出口轮询、背压和初始状态共同决定。不能默认环内各出口平均分流，也不能把可行的 R 当成唯一实际值。

### 初始库存的最小不动点（无需逐 tick 计算）

新增 `factorySteadyGenericStartupReachability(layout,{initialWarehouseItems})`。当机器 FIFO、传送带缓冲初始均为空时，只把无原料生成器作为无条件物料源，仓出仅在对应物品已存在于初始库存或能够由某条仓入线路产生后才成为可能的供给。

令 \(\mathcal P_0\) 为初始可能物料位置集合，\(\Phi\) 代表沿有效线路、端口过滤、机器配方全部原料条件和共享库存进行的传播：

\[
\mathcal P_{k+1}=\mathcal P_k\cup \Phi(\mathcal P_k).
\]

由于图及物品集合有限，且该传播只增加可能的物料位置，迭代达到最小不动点 \(\mathcal P_\*\)。它是**故意宽松的物料可达性上界**：

- 某物品/配方/线路不在 \(\mathcal P_\*\) 中：可以在明确初始状态假设下严格证明其长期平均流率为 **0**。
- 在 \(\mathcal P_\*\) 中：仅说明**可能有物料到达**；不能证明会有正的长期流率，也不能证明 FIFO/轮询能够持续进展。
- 没有初始库存且没有外部生成器的纯分流/汇流闭环，在物料守恒下可以写出形式上的 \(R>0\)，但实际从空缓存无法产生任何物料，因此 \(R=0\)。
- 只要外部生产器、已有库存或初始在途物料能够使回路有物料，上述零证明就不再适用；需要继续联立工作区间。

在 `factorySteadyProveRateBounds(model,{startupLayout,initialWarehouseItems})` 中，可以**显式选择**从指定初始状态推导零上界，并让零值沿现有有理数守恒等式继续传播。默认不提供 `startupLayout` 时保留原来的**不依赖初始状态**的必要上界，不能将这两种不同结论混为一谈。
