# 连续时间供给间隔与普通机器共享入口的代数证明

2026-11-24 修订。替代此前固定步长局部证明。数学模型没有 0.05 秒、时间格、帧数或 tick 参数。模拟器固定步长仅用于独立测试。
范围：理想连续时间事件语义，已就绪到货先于开工；开工释放容量后在同一物理时刻重新判断可接收事件；同一阶段竞争按机器几何右到左。与原游戏及实时 HTML 的全部事件语义等价性尚未证明。

## 1. 供给间隔证书

对同物品合法线路 e 定义 G_e≥P，P 为真实端口最短收发间隔（当前1秒）。G_e 是服务上界，不是平均速率的倒数：初始运输结束后，从该入口一次成功接收开始，下一件兼容物品最迟在 G_e 后具备接收资格；若接收方缓存满，物品可继续等待。该性质与实际接受的长期频率不同。

若发送口在冷却结束且几何空间持续允许后至多等待 d 即发送，且带速 v、间距 s 满足 P≥s/v，则 G_e=P+d。
证明：相邻包裹注入时，前件最多离起点 v(P+d)，后续同速运动且前件可因反压减速，故间距不增；前件被收取后，已注入后件至多 P+d 到达。若前件接收后后件尚未注入，设前件注入时刻 a、达到间距 s 的时刻 b、接收时刻 t，带长 L≥s。后件至迟在 max(a+P,b)+d 注入；t≥a+L/v 且 t≥b+(L-s)/v，因此后件到达不迟于 t+P+d。端口接收冷却也在 P 后结束。所有有效线路均满足正整数带长、v=2m/s、s=1m、P=1s。

### 1.1 自主生成器

每批 b 件、周期 H、输出容量20b。若 H≤bP，从第一次产出开始，任意连续生产区间的累计产量足以供应每 P 一次的发送。若输出缓存曾经阻塞，解除阻塞时已有至少一批的剩余物料，重新生产前的发送也有货。因此发送资格就绪时不缺货，d=0，G=P。

若 H>bP，上一件送出后输出 FIFO 为空则新的批次最迟在 H 后完成，故等效发送资格等待上界 H-P，G=H。该证明只适用于独立无原料生成器，不假设仓库无限供给。

### 1.2 单出口转运和同物品汇流

当输出 FIFO 为空，且存在一个具有 G 证书的输入，该入口最迟在上次接收+G 后有货。在输出队列空时，最后一次接收不晚于最近输出时刻；若有其他入口先补入同物品，也足以服务输出。故单出口转运或同物品汇流的输出证书为已证明输入间隔中的最小值（且 G≥P）。不推导各汇流输入的分配比例，也不对混合物料使用此证明。这里依赖零附加处理时间的连续事件语义。

### 1.3 多出口分流

设分流器单输入供给间隔上界为 G，共有 k 个已连接兼容出口。考察某出口自身冷却完成且始终存在发送空间的时段。只要该出口持续可用，轮询指针至多在它之前成功服务 k-1 个其他出口；每次尚未服务指定出口时，若 FIFO 空，则至迟 G 后可补入一件。只要指定出口可用，就不会因其他出口阻塞而停止发送。故保守发送等待 d≤kG，传送带给出 G_out≤P+kG。若 k=1，使用更强的单出口结论 G_out≤G。没有从该式推出平均分流率。

### 1.4 任意图传播

从可证明自主生成器开始，传播已证明的服务上界；单出口/同物品汇流使用已有输入证书，多出口分流使用上述上界。所有变换非减，按最小上界优先确定线路，每条线路只确认一次。允许任意深度；无已证明来源的闭环不能自证。禁止用数值收敛迭代推算长期速率。混合物料、不兼容、无供给证明的加工输出或仓出暂不传播。

## 2. 全部同物品入口 G_i=P 的批次分配

n 个入口按右到左 i=0..n-1 排序，每次开工消耗 q 个，最短开工间隔 T。要求：

    R=ceil(q/n)
    T≥RP
    nT>qP

在所有入口初始供货完成后，若共享缓存始终未满，每个端口都会每 P 接收，合计 n/P；配方消耗最多 q/T。严格供给余量使有限缓存必然达到满载。满载后只有开工释放 q 个槽位。

开工时记各入口剩余冷却/就绪偏移 δ_i∈[0,P]。该批补料为序列 (δ_i+jP,i), j≥0 的最早 q 个，时间相同按几何优先级；在理想事件模型中开工释放的新容量立即可重新服务。至少有 nR 个候选在 RP 内，补料一定在下次开工前或其接收阶段完成。设 c_i 为本批接收次数，实际下次间隔 Δ≥T，则：

    δ_i' = max(0, δ_i+c_i P-Δ)  (c_i>0)
    δ_i' = 0                     (c_i=0)

这是用于证明的不变量，不是运行时逐批推进算法。

### 2.1 非整除批次 q mod n≠0

设 d=nR-q>0。若没有 δ=0 端口取得第 R+1 件，则所有正偏移不增加，且存在至少一个正偏移端口收到不足 R 件从而变为0：若所有正偏移端口均收到 R 件，较早的零偏移端口也至少收到 R 件，违背 q<nR。

处理恰好同刻边界：第 R+1 件只能出现在 δ=0 的端口且时刻 RP。若有 L 个 δ=P 的端口，则 RP 前累计候选 nR-L；当补料需要使用 RP 同刻事件时，共剩 L-d 件。若其中 z 件被零偏移端口取走，则至少 d+z 个 δ=P 端口少取一件并变为0；新增正偏移端口至多 z 个。故正偏移端口数量严格下降。有限批次后全部 δ=0，且该状态不变。

### 2.2 整除批次 q mod n=0

严格余量给出 ε=T-RP>0。通常正偏移每批减少至少 ε 或归零。若边界上零偏移端口得到第 R+1 件，则至少有同等数量的 δ=P 端口少取一件并归零；每个新增正偏移≤max(0,P-ε)。势函数 Σ ceil(δ_i/ε) 在未对齐时严格下降，有限批次后全部 δ=0。ε 是真实加工周期的余量，不是人为时间步长。

### 2.3 最终等式

相位对齐后每批接收：

    c_i=floor(q/n)+[i<q mod n]
    x_i=c_i ν_m

ν_m 为实际长期批次率。若只开工有限次，有限缓存保证所有相关入流长期为0；若批次率极限不存在，不宣称其数值。这里只证明分配与批次率的关系，不独立决定 ν_m。

## 3. 有界间歇供给的更一般充分条件

已知所有 G_i 有证明，G=max_i G_i。若最短开工间隔 T≥(ceil(q/n)+1)G，则有限缓存终将满载、每批至迟 ceil(q/n)G 补满，下一批开始前所有入口重新就绪。
- q≤n：右到左前 q 个各收一件，其他0。
- n<q<2n：若右到左前 q-n 个入口有 G_i=P 证书，则第一轮所有 n 口各收1件；最早第二轮在 P 时刻，优先前 q-n 个入口恰好满足剩余需求，因此仍可用上一节公式。
- 其他情形不自动确定比例，不把间隔上界当成实际平均供给。

这里的条件保守，可进一步加强，不是必要条件。

## 4. 实现和验证

batch_ready_certificate.js：无固定时间格的连续结构传播及批次证书。
direct_graph.js / direct-worker.js：continuousRefill 研究选项；对满足证书的入口添加精确线性等式。正式入口仍未替换。
- 504630组有理数相位边界与批量组合（含δ=0/P、非整除/整除、不同余量），13项结构拒绝测试全部通过；任意非0.05倍数的有理加工/生成周期不再被拒绝。
- 24层串联转运结构、带额外慢速输入的同物品汇流，均可直接传播 G=P。
- 原双采矿机和合法单出口转运链的真实Edge Worker回归成功；后一布局冶炼左右口为1/4、1/2件/s，装甲净值1/4件/s。
- 有多出口分流的原矿石反例可得到左口G≤3秒、右口G≤1秒，但冶炼最短周期2秒不足以证明同步批次，矿石净值仍未唯一确定。不能从装甲的平均瓶颈周期4秒推出冶炼每次开工间隔至少4秒，因为有限产物缓存允许短期连续加工。
- 原三份大型蓝图浏览器回归通过。该局部连续模型的证明不替代对实际游戏事件语义、分流/汇流长期调度、仓库和混合FIFO的剩余研究。
