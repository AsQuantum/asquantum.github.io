# 结果导向的精确投影研究（未接入）
目标：仓库逐物品收入、支出、净值、潜在净值、透支净值；机器周期与线路流量另作查询，而非要求全变量唯一才输出仓库结果。
实验在原连续方程中只放宽多入口同材料分配。保留各入口容量、总服务量 min(总需求, 总供给)、单口需求上下界以及其余供需方程。该放宽包含此前公平分配和严格连续优先分配，但未证明涵盖真实离散 FIFO 调度。
通过有理线性逻辑求解得到候选模型，对每组目标变量附加“至少一个目标不同”的条件重新检查可满足性。UNSAT 表示该组目标在该数学约束内唯一；SAT 表示有不同结果，UNKNOWN 不可当作唯一。透支模型另行解除仓库限制。
73 台机器：仓库四项以及透支净值均唯一，曲速线圈 20/33 件/min；机器周期组与线路流量存在多解。双入口独立冶炼：仓库 30/min 唯一，入口与采矿机周期非唯一。115 台综合工厂：仓库约束与透支两模型中，仓库指标、周期及线路均唯一。
分流反例：两个供给 1/s 的 A 源。A源1经分流分别连接 A->B 配方与仓库；A源2直连同配方的另一个入口；配方周期1s、每轮耗1A产1B。放宽入口分配后存在 A入库60/min与37.5/min 两个可行精确模型，B入库均60/min。不能全局删除入口分配或分流规则。详见 projection-branch-counterexample.json。
