# 2026-11-24 同时到货的几何优先级
用户明确游戏普通机器同一时刻输入从面向方向右到左处理。
HTML 修正：先移动全部传送带，按接收机器聚合本步到达的队首，再按游戏相对朝向的右侧投影降序尝试接收。AST1 的坐标反射改变显示手性，计算原游戏右侧时反转投影符号。非就绪/冷却/不兼容的入口不阻塞其他入口；同材料 FIFO 仍共享。汇流保持原 RR，仓出保持编号优先。
离散参考 steady-transitions.js 已同步接收事件顺序；它仅用于验证，不作为长期数学求解入口。
离线 export-graph.js 增加 inputPriority、toPort 和 fromPort，exact_reference.py/projection_reference.py 的入口分配实验读取真实几何优先级。
合法等长双入口蓝图，修正后两种线路数组顺序均得到左口 30/min、右口 60/min、钛合金锭 30/min。
验证：四朝向×原坐标/AST1镜像×正反线路顺序，右口未就绪/冷却，以及历史 318 个非浏览器测试和 steady-auto-fluid-browser 均通过。现有历史测试仍针对已发布的连续求解器，不能据此宣称新求解器完成。
结果投影研究：73台新布局仓库20/33 件/min在放宽入口分配的连续模型内唯一；115台综合工厂全部目标唯一；双入口产量30/min唯一而端口/源周期不唯一。仍需证明连续投影与真实事件调度的关系，特别是分流反馈反例和混合FIFO。禁止将严格长期优先当作同时到货优先的一般恒等式。新精确原型未接入正式入口，未提交。
