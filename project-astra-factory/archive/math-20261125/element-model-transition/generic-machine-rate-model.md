# 通用工厂长期产率数学模型（现行正式规范）

版本：2026-11-25，数学源码与网页生产路径统一后。此文档是现行固定帧严格证明合同；[迁移前完整数学推导和所有历史例子](../archive/math-20261125/docs/generic-machine-rate-model.md) 保留原貌。历史连续时间、旧预约、LP/数值迭代及事件周期求解的结果不等于现行理论已证值。历史章节号仅供查阅推导，不是现行模块编号。

## 1. 目标及边界

输入任意合法有限布局、配方、真实端口、线路、共享仓库、冻结配置和指定初态。默认从空仓、空机内栈、空线路启动。求实际长期平均，而非最大产量、某个可行流或者瞬时运行轨迹。允许运行/停机、缓存波动、库存净增长；能证明的查询单独输出，其他明确未知。禁止用 LP、数值固定点迭代、模拟窗口平均、搜索运行周期或预设 AST 结果选取真实速率。图遍历、逻辑条件闭包、精确消元和序号约束的环比证明不属于数值速率逼近。

内部件/秒、批/秒、精确有理数。所有比例、上下界、消元和等号判定用整数分子分母；界面才换算小数。模拟器独立使用既有逐帧实现，只作为验证，不反馈给求解。正式网页由 Worker 计算，HTTP/file 两种入口同源构建。

## 2. 物理结构、初态与计数守恒

每台机器 M=(I,Qin,T,Qout,O,R)，分别为端口、物料共享输入缓存、配方、输出缓存、出口、调度资源。普通配方每种原料独立栈容量3a，成品栈容量20b；开工扣原料，完工入成品栈。端口冷却P=1s，普通同帧输入优先为面向右到左，不能推断长期绝对优先。带速2m/s、最小间距1m、步长1/20s。分流共享FIFO3，汇流共享出口FIFO3，电脑共享FIFO10、销毁1/s。仓入直接增加共享库存。仓出真实缓存3件，补货立即扣仓库，发送不重复扣库；各仓出按真实ID优先，补货与发送时钟独立。当前帧先移动、接收及实体取料，再执行冻结服务，后续配方和派发按真实 simulation.js 因果顺序。物料不兼容的物理线路允许编辑，实际队首在接收端拒绝；悬空线不运行。运行中修改布局/过滤器不清空既有物品，理论另以新布局空启动计算；拆除导致物品返库属于编辑事务，不是持续生产。

令 x_(e,k) 为累计成功通过物品数除以时间的长期平均，ν_m 为累计完成批次除以时间。对任意有界缓存，窗口端点差除以时间趋零，故所有长期聚点都满足：

    0 <= sum_k x_(e,k) <= 1
    0 <= ν_m <= 1/T_m
    sum_(e in I_m) x_(e,k) = a_(m,k) ν_m
    sum_(e in O_m) x_(e,k) = b_(m,k) ν_m

配方有效周期 1/ν，零率为∞；理论占空比 Tν。分汇流逐物品守恒，电脑总销毁≤1/s。冻结工厂共同服务率 α_f∈[0,1]，各物品带符号贡献 v_(f,k)α_f；正源无消耗时 α=1。实际仓库收入 I、支出 X、净值 N=I−X；空启动有 N≥0。反事实透支取消非负库存门槛，负净值合法。无源空启动不可达流及无终点无环有限堆积可证明为零；有源循环或反馈不能一律判零。

## 3. 子图组合及证明模块

物理有向图按SCC缩点，深度 d(v)=1+max前驱深度，根深度0。物理子图与仓库库存依赖分开，后者仍参与整体方程。由真实终点反向传递接收合同，由实际就绪根正向传播供料合同，再精确消元；新已证事实可触发有限逻辑闭包。未纳入的边界不能视作自由出口。所有证明均为必要等式/不等式或带可自动检查前提的充分证书；任何未证前提不得当作成立。

### 3.0 仓入逐线反向物理子图

对每条仓入线路分别作为终点根，向上游追踪所有输入依赖。除仓入外，同一物理机器被不同终点的依赖闭包访问时合并这两个闭包；共用一个分流器、加工栈、仓出缓存或电脑共享FIFO都不能拆开。仓入每个接口直接独立记入库存，不因终点机器ID相同而合并。闭环及未到达仓入的线路也保留，不制造虚拟自由终点。仓出是物理追踪边界；同物品的多个仓出及仓入通过单独库存池关系相连，不把同物品视作同一物理缓存。每条线路属于唯一子图；每个非仓入物理节点至多属于一个子图。

正式编排先生成物理子图及仓库接口表；局部独立加工树和高库存服务容量证明分别在每个子图内运行。允许既有全局轮询、补料、库存耦合及守恒消元处理跨图约束，不假定仓出无限供给，也不声称已将所有复杂子图的求解完全局部化。115机分为12个子图，10个全部线路总流率已证。三个太空垃圾—废料—合金板链各3机3线，产率分别1、2/3、2/9件/s。剩余两图为M48→齿轮机（2线）及三条高级入库线合并的40机53线子图。高级图内11线总率已证，42线未知。另有仓库跨图关系未闭合。

### 3.0.1 完整物理图的生成语法与数学组合

令物理子图 G=(I,M,F,E)，x=|I|、y=|M|、z=|F|。正常生产图要求 x>=1、y>=0、z>=1。I 指自主生产与仓出真实输出端口；M 指加工、分流、汇流及其任何组合；F 指独立仓入端口（每台最多3）及独立销毁端口（电脑每台1）。仓出不是物理终点。没有源或终点的实际布局也必须保存并诊断；无源空启动可由可达性证明零，无终点有限缓存的无环图可由守恒证明零，有源物理循环不可直接判零。拓扑不按固定 x,y,z 枚举有限图形，因为中间机器数、连法及环可任意增长，而由以下有限局部语法生成全部图：

| 局部构件 | 端口度（输入,输出） | 必要数量关系 | 额外决定性关系 |
|---|---|---|---|
| 自主源 | 0,1 | x=bν, 0<=ν<=1/T | 周期批次、有限成品栈、输出可用时钟 |
| 仓出 | 0,1 | x<=1 | 同物品库存、3件补料栈、优先级及独立冷却 |
| 普通加工 | 1..4,1 | 各物品输入和=a_kν，输出=bν | 共享原料栈、同时开工守卫、反压释放节拍 |
| 分流 | 1,1..3 | 逐物料入=出之和 | RR指针、跳过条件、过滤阻塞、各支路接受机会 |
| 汇流 | 1..3,1 | 逐物料出=入之和 | RR接收、共享FIFO、混料次序 |
| 仓入 | 1..3,0 | 每线独立入库 | 每个接收口1/s，无共享接收栈 |
| 销毁 | 1,0 | 销毁率=入流 | FIFO10、1/s消费、输入间隔>=1s |
| 带 | 1,1 | 同物品发送与接收长期相等、总流<=1 | 真实长度、在途有序队列与有限空间 |

合法组合由上述端口配对得到；每个端口至多一条物理线。串联、汇合、分支、分支再汇合、多源多终点、物理反馈、混料、共享原料缓存是可重叠拓扑性质而非互斥案例。任意有向图可按 SCC 缩点成 DAG；在 DAG 上逐深度传播，在 SCC 内联合证明。对物理拓扑完整的判定不等于数学上已有闭式解。对于各端口的累计序列 S_e(t),R_e(t)，有限在途量满足 0<=S_e-R_e<=K，连续成功发送或接收的时刻间距>=P。加工状态对每种输入和成品的有界库存满足累计差分守恒；开工还需要所有原料足量、成品空间及前批完成。分汇流额外保留实际RR状态、FIFO队首、冷却及阻塞守卫。不能用平均值相等代替这些守卫。

子图接口应是关系 C(A,B) 而非单个平均流率：A 为所有边界供给事件/数量约束，B 为所有边界接受/空间约束。现行实现能传递精确流率、容量界、自由接受、就绪时钟、批次节拍、序号图及部分到货日历；一般共享资源的完整 C(A,B) 仍缺失。组合仅对真实连接边界消元，不能假定剩余子图自由或按名义容量运行。

### 3.1 物流、就绪与反压

- 自由终点允许P间隔的合法到货；单输入、单物料、单位产出加工机若 P≤T≤aP 且后继自由，可以向上游传递自由接收。缓存不积满是原因，非该机一定满速。
- 就绪时钟 h 约束上一件成功接收后下一件最迟何时到达队首，不等于实际平均率。两/三路饱和汇流，兼容、轮询且输出自由时总率1/P，已证永久就绪输入轮询份额相等；反压时相等关系可保留，但总率未知。自由分流支路份额相等，其他支路不超过自由份额；不假定受压支路均分。
- 饱和分流的n个兼容接通出口，每支路在空间恢复、接口冷却均具备后，至多经过n次成功扫描取得服务。保守事件上界 S_j≤max(S_(j−1)+nP,R_(j−K)+d+nP,C)，K=L+1，d=P/2。快慢图斜率相等才认证实际率。若独占原料接口的供料时钟为h_k，单位产出且成品自由，则批间隔上界 H=max(T,max_k a_k h_k)，故 ν≥1/H。
- 反向精确节拍：满足单位产出、原料就绪、专属下游每批消耗1件及严格时间余量时，有限缓存的空位节拍可反传。两同料入口、批量q=2或3、已证节拍H>qP且低优先时钟<h条件中的严格余量成立时（实际检查为H>低口时钟），高优先每批q−1、低优先1。仅名义周期或平均率不能代替精确节拍。
- 两路分流的一路自由，另一路进入兼容二输入汇流且汇流输出自由，固定帧等待界和带容量排除首次轮询跳过时，两支路均为总率一半。可用于有源回流，但必须证明真实自由出口、库存/源供给及兼容性。
- 混合FIFO、一般受阻再汇合、批量相位及共享原料竞争尚未完备，不能套平均公平公式。

### 3.2 序号图

独立加工树的批序号、收发序号及有限缓存释放组成有向带权滞后边：t_v(j)≥t_u(j−l)+w。固定帧因果边以有理数表示；当全部真实资格约束以最大值递推等式刻画且启动边界有限时，长期序号块时间等于最大环权/滞后比。给定下界λ由实际临界环达到；若存在势 h 满足每边 h_v≥h_u+w−λl，则同为上界。必要时使用原有精确环比算法；不展开真实运行轨迹。共享分流/汇流根用保守最快与最慢事件图夹逼，同斜率才能确定实际率。拒证时可保留经证明的界，不写成唯一值。

### 3.3 仓库和冻结

共享仓库 N>0 或严格正下界意味着库存最终超过任何有限取料门槛；据此解除该物品缺料约束，继续证明其他物理限制。已证高库存服务合同且无未确定共享竞争时，累计守恒和最后低库存区间可得到总消耗=min(可用收入,需求容量)。独占多原料加工树的共同缩放为各必需物品可用收入/满速需求与1的最小值。若其他消费者未证、库存反馈未闭合或边界服务不足，则保留未知或残余上下界。实际仓出与冻结内部优先必须遵从帧内顺序及有限缓存，不能把平均供给直接按长期绝对优先分完。

独占输入冻结网络：对每配置 f，α_f=min(1,min_k I_k/a_fk)，其中 I_k 包括独立已证实体收入和其他冻结贡献。仅独占、无其他潜在实体取料者（含未接线仓出）且外部计数已证时成立。无环依赖可拓扑代入；独占反馈使用精确分支消元，仅接受所有允许固定点一致的坐标，或独占转换环闭式证明。不能任取固定点，不用数值迭代；无源空启动以可达性判零。共享不足与多方竞争仍有未闭合情况。

### 3.4 最高优先级仓出的到货时钟证明

对于独立无阻塞单原料链，自主源每周期T产出b件，T≥bP，则空启动发送时刻为T+nT+jP（0≤j<b）。传送距离L引入L/2秒。下一加工机每批消耗a件，其开工时刻为上游每第a件到达时刻；若相邻开工间隔≥max(T_new,b_new P)，则没有积满或完成阻塞，下一批发送/到货时刻直接由前述序号表达式加T_new、jP及L/2得到。使用整数帧、批次数最小公倍数构造有限相位表，而非寻找模拟周期。任何单线、专属物料、时间或缓存条件不满足时拒证。

从这些独立真实入库相位中选取间隔≥P的服务槽，周期H、每周期B槽。最高优先仓出在某服务槽若缓存有空间且冷却结束，必先获得该到货，不论其他仓出是否就绪或被反压。保守虚拟补料F_j按下一个服务槽推进；最早资格由前一虚拟补料及真实第j-3次发送后的下一帧决定。虚拟槽序号递推展开后，任意起始相位至第l槽的等待上界W_l为l个连续循环间距的最大和，故保守序号图增加：

    F_j <= max(F_(j-B)+H, max_(0<=i<B)(S_(j-3-i)+δ+W_(i+1)))
    S_j <= max(F_j,S_(j-1)+P,R_(j-K)+d)

这里F为保守虚拟补料时间上界，不是实际补料的等式；第二式使用其上界。将这些依赖作为较慢的最大值递推图，若原全供给图已经证明临界块时间λ，且慢图每条边均具有满足λ的势函数，则原真实计数受两个模型夹逼得到相同长期率。比较上界接口仅返回upper-proved，不能单独当作精确临界环。只用于最高优先、单仓出根独立加工树、真实兼容路径，排除冻结物料竞争及根透明中继；任意未证其他源不会削弱所选真实到货槽。

### 3.5 按库存依赖求解：相对服务与最后低库存证明

物理形状不是数学求解分类的主轴。对子图G取仓出物料集合A(G)和仓入物料集合B(G)。A为空为无库存依赖，可独立证明物理率（有物理环仍需环证明）；否则通过物料池及冻结配置的有向依赖图判断无环依赖或反馈依赖。A∩B非空是直接返仓，间接跨图反馈仍由SCC识别。另将同物料多个仓出/冻结消耗标为竞争；竞争即使在无环图也需联合服务约束。已证平均值可消除未解率依赖，但不可据此删除真实时间耦合。分类是诊断与编排，不是假定分配等式。

精确区间投影在等式消元时优先保留配方批率及冻结占空比坐标，再由单变量有理上下界消除必然成立的多变量行。只改变精确基底、删除逻辑冗余，不引入目标函数。115机七自由度的初始剩余模型在本轮实验中原来超过千条中间约束且投影失败，改进后各关键查询最多35条有效行，可给出精确区间。仅有区间不表示已经确定实际率。

**分流相对服务定理（保留真实冷却和有限缓存）。** 对同质兼容n路分流，令A(t)为其累计成功输入接收。输入接收至少间隔P=1s，定义时钟θ在每次接收时为A(t)P，相邻接收之间作线性插值，故单调且1-Lipschitz。不能直接用输出总派发时钟，因为堵塞解除后的共享FIFO可出现跨端口突发。某支路持续有空间且冷却就绪时，最多n次成功轮询被选；期间每一新输入在当帧触发一次成功派发，所以至多n个虚拟时钟单位。上次派发后开区间P内至多一个新输入：若它触发其他端口派发，指针已前移，剩余至多n−1次；若没有，它仍在FIFO，冷却结束后先发生不消耗新输入的一次派发。若达到n个新接收，最后一次与本支路派发同帧，因此线性插值不多计分数。若带空间更晚恢复，从恢复时刻应用n次扫描界。对长度L带使用向前移Ld的时钟，K=L+1，真实接收间隔P保证R_(j-K)+d<=R_(j-1)-Ld。结合带头到达序号关系，得到下一合法接收至多n个虚拟时间单位；有限首项/窗口端点只贡献有界常数。

对于单一目标分流分支、每种原料独占一接口、单位批产出且已证成品自由的加工机，其余原料来自独立自主单位源、直接充足仓出或单层同质充足仓出分流。保守实际头时钟分别为T_source、P、(n_other+1)P。各仓出门槛在整个所考察区间均充足时，统一使用上述虚拟时钟，其他真实时钟由于1-Lipschitz不增加；上一批开始后如果下一批尚未开工，已补齐的原料不再减少。故批开始虚拟间隔至多 H=max(T,a_target*nP,max_k a_k h_k)，得到每个充足区间批次数差>=P·ΔA/H−O(1)。常数仅依赖有限线路、缓存和周期，不依赖区间起点。其他物料短缺、无出货合同、混料或共享原料缓存不能套用。

**解除充足库存前提。** 对每个其他仓出门槛k，在现有必要前缀计数约束中暂时添加 net_k=0，精确投影相对不等式 r−(P/H)x。若每个低库存条件下下界均>=0（或低库存条件与必要约束矛盾），则实际任意长前缀的最后低库存帧s处该相对计数关系成立至o(s)误差：否则有界归一化计数存在违反条件的聚点。此后所有门槛充足，用相对服务区间界补齐s到t，得到对全部长期聚点的必要不等式。无需假定所有平均值已存在；条件等式只用于检查低库存情形，不加入正式模型。已证严格正净值下界的门槛最终永久充足，可直接跳过。实现 relative_splitter_service.js。

**自由仓出前缀剩余供给。** 已证收入I、各竞争者前缀率上界U_j以及自身自由1/s接收合同，取最后低库存s。在s处自身累计取出>=I·s−sum(U_j)·s−o(s)，之后永久库存充足且自由仓出至t按1/s运行。因此自身长期下界max(0,min(1,I−sum U_j))。其他竞争者上界可由全图精确投影给出；绝不将只对前缀有效的界套到任意短区间。

115机设X为M50合金板支出，C、F、M分别为共鸣水晶、框架、电动机批率。已证M49=1/3，故 X<=1/3；守恒X=2C+4F+M。新增相对证明 C>=2X/15、M>=X/12，均通过其他库存低时的条件投影；所以4F<=13X/20，M114=6F<=13/40。钛锭收入4/3，M48自由，剩余供给4/3−13/40>1，故M48=1、M31齿轮产量1/2件/s。钛锭净值>=1/120，齿轮净值>=7/90件/s（仅下界，不作为精确净值显示），这两个库存门槛最终充足。实际唯一查询319→335/626、仓库未知58→57；12个物理子图中11块全部线路总流率已证，仅高级加工联合图未全解。透支仍366/626。正式算例 EX-RELATIVE 及实际AST、浏览器和历史回归共同验证。

### 3.6 高库存需求耗尽（零净值）

已证某物料的入库前缀斜率 I。将已证的独立仓出及冻结消耗的完整前缀率计入 D_0；再取不重叠的其他仓出支路，其加工机各原料独占接口、单位产出、成品具有全局自由接收合同，输入限于直接仓出、单层同质分流仓出或自主单位源。其他库存门槛均已证最终充足。假设待查询库存保持高位的一段区间，直接及分流供料时钟分别为 P 和 nP（第3.1节服务合同），以 H=max(T,max_k a_k h_k) 给出该加工机的区间批率下界。该物料消耗下界 a/H；各支路可以相加，但已计入完整仓出的支路不得重复计入。任意区间起点的有限在途/缓存及冷却启动误差由固定拓扑的有限界吸收。

若 D_0+sum(a/H)>=I，取最后一个低库存帧 s。在 s 库存有界；其后全部相关库存高位，收入斜率已知、完整已证消耗的区间计数为两个已证前缀之差，其他支路由服务合同给出区间下界。所以库存(t)<=o(t)，非负性推出 net=0。若其他库存可能持续不足、过滤不兼容或输出自由合同缺失则拒证。不能将此条件需求下界直接当作实际生产率。

115机例：钛锭与齿轮库存最终充足，M33在合金板充足区间的H=max(6,6*1,4*3,2*2)=12秒，因此M50的框架支路消耗至少1/3件/s。M49已证完整消耗1/3件/s，合计2/3件/s等于收入。故合金板实际净值=0，支出2/3件/s，M50=1/3件/s。其余三分流份额仍未知。实际已证347/626，透支366/626，仓库未知55/75。正式测试 EX-EXHAUSTION 与实际AST、网页逐项审计。

## 4. 五项仓库指标与输出

实际收入 I、实际支出 X、实际净值 N=I−X。潜在净值 P_k=I_k−D'_k：保持当前稳态收入，仅缓解被查询物品的缺料限制，求其条件需求；其他物料及真实下游限制仍保留。若 N_k>0，该物品的库存限制已经永久失效，P_k=N_k。N_k=0 不代表供需恰好平衡。透支净值 O_k=I*_k−X*_k：独立取消全部库存非负限制、重新证明整个工厂平均值；不复制潜在净值。冻结导入可选择本地实际净值或本地潜在净值，禁止重复导入原冻结来源；未知值不当0。各列独立证明，合计也可独立由必要方程确定。真实 UI 所有理论字段保留分式，显示适配器才转小数。失败、未知、已证零、部分解四种状态明确区分。
