地图规则

可建造区域72×72 − 中央14×14
导入文件必须是包含 machines 与 routes 的布局 JSON；产能蓝图、流量审计 JSON 不能当作地图导入。
橙/蓝接口在机器内部；绿线只走机器外的格。普通传送带一对一，2米/秒、堵塞时1米停靠间距；起终点位于接口格的外侧边中点；每格只有4种有向直线和8种有向直角。交叉格仅能容纳互相垂直的两条直线，每格最多一个十字，不能转弯、合流或交换物品；穿过后可拐弯。分/汇流必须使用3×3设备。分流器未接线的出口允许贴着其他机器，不会强制保留外侧格。
